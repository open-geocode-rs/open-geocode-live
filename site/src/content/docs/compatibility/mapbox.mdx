OpenGeocode serves Mapbox Geocoding v6 and Search Box v1. Use Geocoding for addresses and batch lookups, or Search Box for place search and suggestions.

## Change the endpoint

Replace `https://api.mapbox.com` with `http://127.0.0.1:8080/compat/mapbox`. Keep the versioned path and drop the `access_token` parameter.

If you use `@open-geocode/client/mapbox`, change the client configuration. Your existing method call stays the same.

```diff
-const client = mapbox({ accessToken: mapboxToken });
+const client = mapbox({ baseUrl: "http://127.0.0.1:8080" });
```

## Geocode an address

Look up [the Library of Congress Thomas Jefferson Building](https://www.loc.gov/visit/directions/).

Serve the [USA Pack](/docs/guides/download-packs/). For TypeScript, [build the SDK from source](/docs/guides/typescript/#install-the-client).

<Tabs>
<TabItem label="TypeScript">

```typescript
import { mapbox } from "@open-geocode/client/mapbox";

const client = mapbox({
  baseUrl: "http://127.0.0.1:8080",
});

const { features } = await client.geocoding.forward({
  address_number: "10",
  street: "1st Street Southeast",
  place: "Washington",
  region: "DC",
  postcode: "20540",
  country: "US",
  limit: 1,
  autocomplete: false,
});

const match = features[0];
console.log(
  match?.properties.full_address,
  match?.geometry.coordinates,
);
```

</TabItem>
<TabItem label="cURL">

```bash
curl --get 'http://127.0.0.1:8080/compat/mapbox/search/geocode/v6/forward' \

  --data-urlencode 'place=Washington' \
  --data-urlencode 'region=DC' \
  --data-urlencode 'postcode=20540' \
  --data-urlencode 'country=US' \
  --data-urlencode 'limit=1' \
  --data-urlencode 'autocomplete=false'
```

## Supported endpoints

Paths are relative to `/compat/mapbox`.

| Operation | Path | Behavior |
| --- | --- | --- |
| Forward and reverse geocoding | `GET /search/geocode/v6/forward`, `GET /search/geocode/v6/reverse` | `geocoding.forward()` and `geocoding.reverse()` |
| Batch geocoding | `POST /search/geocode/v6/batch` | `geocoding.batch()` |
| Suggest and retrieve | `GET /search/searchbox/v1/suggest`, `GET /search/searchbox/v1/retrieve/{id}` | Pass the suggestion's `mapbox_id` to `retrieve()` and reuse the session token. |
| Search Box forward and reverse | `GET /search/searchbox/v1/forward`, `GET /search/searchbox/v1/reverse` | `searchbox.forward()` and `searchbox.reverse()` |
| Categories | `GET /search/searchbox/v1/category/{id}`, `GET /search/searchbox/v1/list/category` | Category search uses the OpenGeocode category list. |

## Follow-up requests

Pass the suggestion’s `mapbox_id` to `retrieve()` and reuse the `session_token`. Read GeoJSON coordinates in longitude, latitude order.

## What OpenGeocode leaves out

| Feature | What happens on OpenGeocode |
| --- | --- |
| Geocoding v5 and Directions | Use Geocoding v6 for address lookups. Keep Directions on a routing service. |
| Route and ETA options | Search Box rejects `route`, `eta_type` and `navigation_profile`. |
| Mapbox’s POI catalog and category list | OpenGeocode searches places in your Pack and publishes its own list of category IDs in English. |
| Mapbox-issued feature IDs | Search or suggest on OpenGeocode to get an ID you can retrieve. |
