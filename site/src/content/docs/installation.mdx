The installers and release archives include both `og` and `open-geocode`. They run without Rust or Cargo.

## Install a prebuilt binary

On macOS and Linux, the [shell installer](/install) installs the latest stable release. It needs Bash, curl and tar with xz support.

On Windows x64, the [PowerShell installer](/install.ps1) installs the latest stable release.

<Tabs>
<TabItem label="macOS & Linux">

```bash
curl -fsSL https://opengeocode.com/install | bash
```

</TabItem>
<TabItem label="Windows">

```powershell
powershell -c "irm https://opengeocode.com/install.ps1|iex"
```

</TabItem>
</Tabs>

Open a new terminal if the installer updated your `PATH`, then run:

```sh
og --version
```

## Install a specific version

On macOS or Linux, pass a release tag such as `v1.0.0`. The installer also accepts the `og-v1.0.0` spelling.

```bash
curl -fsSL https://opengeocode.com/install | bash -s -- og-v1.0.0
```

On Windows, run the PowerShell installer from the [GitHub release](https://github.com/open-geocode-rs/open-geocode/releases) for the version you want.

## Install with Cargo

This option requires Rust 1.88 or newer and Cargo. Get both from [rustup.rs](https://rustup.rs).

```sh
cargo install --locked open-geocode --version 1.0.0 --features tui
```

Continue with the [Quickstart](/docs/quickstart/) to build and serve a Pack.
